# Staff guide — table codes (one page)

Print this and keep it by the till.

## The one rule

**Give the code only to guests sitting at that table, in person. Never read it across the room and
never write it on the table.**

## What happens when a guest taps the sticker

1. Their phone opens a page asking for a code, and a card appears on your screen with a sound and a
   vibration (a rising three-note tone — not the order chime).
2. The card shows the table number, a big **4-digit code**, how long they have been waiting, and
   whether the table already has a visit open ("open 20 min · 2 phones").
3. Walk over, check they are really seated there, and **read the code out**. They type it and they
   are in.
4. More phones at the same table use the **same code** — read it out again, do not make a new one.

Cards turn **red after 2 minutes**; the manager gets an alert after 5 minutes.

## The three buttons on a card

| Button | Use it when | What happens |
| --- | --- | --- |
| **Dismiss** | Nobody is at that table, or it is a mistake | The card disappears for everyone. The guests at that table would need a new code |
| **New code** | The code was overheard, or the guest mistyped it too many times ("Locked after 5 wrong tries") | Old code dies instantly, a new one appears. Phones already inside keep working |
| **New party** | There are guests at the table, but the visit on screen belongs to the last group ("A visit is still open on this table") | Closes the old visit, keeps its orders in the reports, frees the table. The next code starts a clean visit. Works for waiters and managers alike |

## Common situations

**"I never got a code."**
Check the board — if there is no card, their tap did not reach us. Ask them to tap again. If your
screen shows "No staff device is online" they will see a message asking them to call you.

**"It says the code expired."**
Codes last 10 minutes. Press **New code** and read the new one out.

**"The code is locked / too many attempts."**
Press **New code** and read it slowly, digit by digit.

**A guest lost their phone or left and came back.**
Their session is still open: **Dismiss** is not needed, just read them the code again. If they closed
the browser, the same code still works while it is live.

**A guest says "I'm not ordering, just looking."**
Fine — they can browse the menu before entering the code. They only need it to order, call you, ask
for the bill, review, use the Wi-Fi or play a game.

**Two groups, one table — the second one just sat down.**
Press **New party**. The first group's orders stay on the bill; the new group starts a fresh visit.

**The code was seen by someone at another table.**
Press **New code** immediately. Their phone keeps working — only the code changes.

## End of day / something went wrong

Admin → **Settings → Table codes & sessions → End all sessions and codes**.
Every table goes Free, every code dies, every guest has to ask for a new code. Use it when you
suspect a code leaked, or before you close.

## Do not

* Do not shout a code across the room, and do not leave a printed list of codes at the counter.
* Do not give a code to someone standing at the counter who is not at that table.
* Do not give the **Wi-Fi password** before the code is entered — the app only shows it inside a
  verified visit, on purpose.

Manager settings live in Admin → Settings: code length (4–6 digits), how long a code lasts (3–30
min), wrong tries before it dies (3–10), how long "Ask again" is blocked (0–300 s), phones per table
(4–20), idle timeout (30–240 min) and the hard cap (1–8 h).
